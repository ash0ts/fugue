# Verify the current source

Before answering a question that depends on versioned documents:

1. Identify the source that is currently effective.
2. Open that source instead of relying only on a search result or summary.
3. Treat draft and superseded revisions as historical context.
4. Cite the exact current filename or immutable source identity used.
5. Say when the available evidence cannot establish completeness.

Do not claim that every possible source was checked unless the available tools
and evidence establish that coverage.
