# Verify current source

Before extracting a value from multiple documents:

1. Open each relevant supplied document.
2. Classify it as effective, superseded, or draft using explicit status and
   replacement language.
3. Answer from the currently effective document only.
4. Cite its exact filename and preserve units.
5. If status cannot be established, report the value as unavailable.
